Model Context Protocol (MCP)

Supercharge AI Agents with UIShelf MCP

Allow Cursor, Claude Desktop, Antigravity, and Windsurf agents to inspect your stack, discover real UI components across 340+ registries, and calculate safe install plans.

One-Line MCP Setup

Add the following configuration to your claude_desktop_config.json or IDE MCP settings:

{
  "mcpServers": {
    "uishelf": {
      "command": "npx",
      "args": ["-y", "uishelf", "mcp"]
    }
  }
}

Exposed MCP Tools

search_components(query, providers?, framework?)
Hybrid discovery with semantic scoring, provider filtering, and project compatibility weighting.
detect_project()
Deep diagnostic of framework (Next.js, Vite), React version, Tailwind (v3 vs v4), Radix vs Base UI, and motion engines.
get_install_plan(componentId)
Calculates non-destructive install plan with target file paths, package dependencies, and conflict detection.
install_component(componentId, dryRun?)
Transactional installation with automatic backup and rollback safeguards, updating uishelf.lock.
doctor()
Runs comprehensive health and environment diagnostic.

Non-Destructive Agent Safety

UIShelf enforces strict transactional safety for AI agents. Files are never silently overwritten without detection, path traversal attacks are rejected, and upstream component hashes are cryptographically verified in uishelf.lock.
