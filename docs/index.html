Architecture & Technical Documentation

Comprehensive guide to UIShelf Core, provider abstractions, and safety mechanisms.

Non-Negotiable Architecture Principle

UIShelf Core contains all business logic. The Web application, the CLI, and the MCP server invoke the exact same core orchestration layer. Provider integrations are decoupled through the UIShelfProvider interface.

UIShelf Core
    │
    ├─ Web Application (Next.js)
    ├─ Interactive CLI (uishelf)
    └─ Model Context Protocol (MCP Server)
          │
    Provider System (shadcn registry, 21st, package libraries)

Transparent 9-Factor Quality Scoring

Unlike simple star counts, UIShelf calculates a transparent, multi-dimensional quality score with full explanations:

  • Compatibility: 20% — Match against project React, Next.js, and Tailwind versions.
  • Code Quality: 15% — TypeScript rigor, clean interfaces, and slot polymorphism.
  • Accessibility: 15% — WAI-ARIA compliance, focus trap, and screen reader labels.
  • Maintenance: 10% — Registry uptime and recent check health.
  • Documentation: 10% — Descriptions, examples, and prop types.
  • Performance: 10% — Zero bloated runtime overhead.
