Developer CLI

UIShelf Command Line Interface

Fast, interactive, and scriptable. Built-in --json support across all commands for automation and CI/CD pipelines.

Command Referencev0.1.0
uishelf init$ npx uishelf init

Initialize UIShelf configuration and scan project stack

uishelf search <query>$ uishelf search 'animated pricing'

Search across 340+ registries with compatibility scoring

uishelf add <component>$ uishelf add @magic-ui/magic-card

Install component with transactional safety and lockfile update

uishelf add <comp> --dry-run$ uishelf add @aceternity/3d-card --dry-run

Preview file changes and packages without modifying disk

uishelf inspect <component>$ uishelf inspect @cult-ui/text-gif

Deep-dive into component AST, source code, and dependencies

uishelf doctor$ uishelf doctor

Diagnose project framework, Tailwind config, and provider status

uishelf providers list$ uishelf providers list

List all active, verified, and community providers

uishelf providers sync$ uishelf providers sync

Fetch and index the official shadcn registry index

uishelf providers add <name> <url>$ uishelf providers add acme https://acme.com/r/{name}.json

Register a custom community or enterprise registry URL

uishelf verify$ uishelf verify

Verify cryptographic SHA-256 integrity hashes in uishelf.lock

uishelf audit$ uishelf audit

Scan installed UI components for suspicious code or eval() calls

uishelf mcp$ uishelf mcp

Start Model Context Protocol (MCP) server over stdio
